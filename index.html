FYP Methodology & Mathematical Proof

Comprehensive theoretical foundation, MSB bit manipulation formulas, and algorithmic flowcharts for your FYP report.

1. Stage 1: Pixel Permutation

Spatially scrambles pixel coordinates using a Fisher-Yates shuffle seeded by the SHA-256 password PRNG:

For k = M-1 down to 1:
  j = PRNG.nextInt(k + 1)
  swap(Perm[k], Perm[j])

Destroys spatial auto-correlation and object boundaries.

2. Stage 2: RGB Channel Permutation

Permutes the color channel order [R, G, B] per pixel using 1 of 6 bijective group permutations:

PermId = PRNG.nextInt(6)
[R', G', B'] = Permute([R, G, B], PermId)

Scrambles color chrominance and breaks channel inter-dependencies.

3. Stage 3: 2-MSB XOR Encryption

Extracts top 2 MSB bits (b₇b₆) of every color byte and XORs with password-generated 2-bit key K₂ ∈ {0..3}:

b₇b₆' = b₇b₆ ⊕ K₂
Byte' = (Byte & 0x3F) | (b₇b₆' << 6)

Preserves lower 6 bits (b₅..b₀) while injecting strong pseudo-random visual noise.

4. Proof of Exact Lossless Decryption

Decryption executes the inverse operations in exact reverse order:

Encrypted → Undo 2-MSB XOR → Undo RGB Perm → Undo Pixel Perm → Original Image (MSE = 0.00, PSNR = ∞ dB)

100% reversible, mathematically lossless recovery when provided the matching key.
